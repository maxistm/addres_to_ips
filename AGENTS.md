# AGENTS.md

Инструкция для агентов, работающих в этом репозитории.

## Назначение проекта

Проект `addres-to-ips` ищет IPv4-адреса, связанные с DNS-именем или URL, и строит результат в виде списка IP, WireGuard-конфигурации или команд для Keenetic.

Поиск адресов выполняется через `Playwright` и сетевые запросы браузера, а DNS-резолв работает через выбранные DNS-серверы.

## Технологии

- Python 3.12
- FastAPI
- Uvicorn
- Playwright
- dnspython
- Jinja2
- HTML, CSS, JavaScript для веб-интерфейса
- Docker Compose для деплоя

## Структура проекта

- `main.py` — CLI-логика и основной алгоритм поиска IP
- `app.py` — FastAPI-приложение и HTTP API
- `templates/` — HTML-шаблоны веб-интерфейса
- `static/css/` — стили фронтенда
- `static/js/` — клиентская логика UI
- `deploy/` — Dockerfile, docker-compose и скрипт деплоя
- `golang/` — вспомогательная Go-реализация
- `README.md` — описание проекта и способы запуска
- `pyproject.toml` — зависимости и метаданные Python-проекта

## Как запускать

- Установка зависимостей: `uv sync`
- Установка Chromium: `PLAYWRIGHT_BROWSERS_PATH=0 uv run playwright install chromium`
- CLI: `PLAYWRIGHT_BROWSERS_PATH=0 uv run python main.py example.com`
- API: `PLAYWRIGHT_BROWSERS_PATH=0 uv run uvicorn app:app --host 0.0.0.0 --port 8000`
